# Windows 真实设备验收清单

此清单必须分别在至少一台真实 Windows 10 x64 和一台真实 Windows 11 x64 桌面电脑完成。GitHub Runner 结果不能替代真实设备。首个 `1.0.0` 之前需把两份已填写记录提交到仓库；未完成时 `0.x` 保持 prerelease。

完成后还要更新 `config/desktop-acceptance.json` 的日期和证据路径；构建工作流会对 `1.x` 及更高版本强制检查两台真实设备记录。

## 记录信息

- [ ] 系统：Windows 10 / Windows 11（版本与 build）
- [ ] CPU/系统类型确认为 x64
- [ ] 测试日期、测试人、设备标识（不得包含敏感资产信息）
- [ ] 安装器版本、文件名、SHA-256
- [ ] Authenticode/SmartScreen 状态：签名有效 / unsigned 警告符合预期

## 每个系统必须完成

- [ ] 普通非管理员用户交互安装成功，中文界面与英文界面各至少验证一次
- [ ] 静默参数 `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART` 返回 0
- [ ] 包含空格和中文的用户配置文件/测试路径不导致截断或乱码
- [ ] 固定目录、manifest、HKCU discovery 和三个开始菜单入口正确
- [ ] 桌面无快捷方式，用户/系统 PATH 与环境变量没有被修改
- [ ] 目标端断网后仍可完成安装和全部验证
- [ ] 全部 14 个直接包及传递依赖版本与 manifest 一致，`pip check` 成功
- [ ] Selenium/webdriver-manager 验证不启动浏览器、不下载驱动
- [ ] 同版本健康重跑保持环境；人为制造漂移后重跑会事务式重建
- [ ] 更高测试版本可向前升级；较低版本被拒绝且当前环境保持可用
- [ ] 安装失败模拟保留旧环境和日志，不发布 staging 路径
- [ ] 卸载私有运行时后 owned runtime、venv、开始菜单和注册表被移除，日志保留
- [ ] 复用外部 CPython 分支卸载后外部解释器完全保留
- [ ] 日志为英文 UTF-8，未发现 token、密码、证书或完整环境变量
